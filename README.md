# How Am I

A collection of tiny, single-file websites — each under 14KB — that answer one question using your phone's sensors. No frameworks, no build step, no external requests.

- [`how_high_am_i`](https://jakub-domogala.github.io/How-Am-I/how_high_am_i/) — current altitude
- [`how_fast_am_i`](https://jakub-domogala.github.io/How-Am-I/how_fast_am_i/) — current speed
- [`how_steep_am_i`](https://jakub-domogala.github.io/How-Am-I/how_steep_am_i/) — current incline
- [`how_overloaded_am_i`](https://jakub-domogala.github.io/How-Am-I/how_overloaded_am_i/) — current g-force
- [`how_loud_am_i`](https://jakub-domogala.github.io/How-Am-I/how_loud_am_i/) — current sound level
- [`how_far_am_i`](https://jakub-domogala.github.io/How-Am-I/how_far_am_i/) — distance from home
- `pro` — all of the above combined (coming soon)

Each subfolder is a fully self-contained `index.html` (inline CSS/JS, system fonts only) so every page loads in a single HTTP request.
